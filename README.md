# Shree Lakshmi Bhavan Staff Manager

An offline-first staff directory, attendance tracker, payroll manager, loan ledger, and payslip generator for Shree Lakshmi Bhavan.

## Run locally

Prerequisite: Node.js.

```sh
npm install
npm run dev
```

Run `npm run lint` for the TypeScript check and `npm run build` to create a production build.

## Fresh start

The app opens with an empty roster and blank company contact details. Use **Fresh Start** to clear all staff, attendance, payment, loan, and company details and restore the Shree Lakshmi Bhavan defaults. Records are stored in this browser's local storage.
